# <img src="https://cdn-icons-png.flaticon.com/512/188/188940.png" width="45" align="center"> Pokédex Online

> Projeto desenvolvido para a disciplina de **Laboratório de Programação**, com o objetivo de criar uma **Pokédex Online**, permitindo consultar e visualizar informações sobre diferentes Pokémon através de uma aplicação web.

---

## 🎯 Sobre o projeto

A aplicação será uma **Pokédex online**, desenvolvida como projeto acadêmico e construída gradualmente ao longo do bimestre.

A proposta é criar uma interface web onde o usuário poderá consultar Pokémon e visualizar suas principais informações de forma organizada e intuitiva.

---

| ------------------------ | ------------------------------------------------------------------------------------- |

| **MySQL Driver**         | Permite a comunicação da aplicação Java com o banco de dados MySQL.                   |

---

## 📚 Estrutura do projeto

O projeto será desenvolvido utilizando **Java + Spring Boot**, seguindo uma estrutura organizada para separar as diferentes responsabilidades da aplicação.

Durante o desenvolvimento, novas funcionalidades serão adicionadas e versionadas através do Git.
